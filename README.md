# DEYOUNGTECH E-Commerce

A production-oriented full-stack e-commerce platform built with React, Node.js, Express, and MongoDB.

## Stack

- React + Vite
- Node.js + Express
- MongoDB
- JWT authentication
- Paystack + Flutterwave payments
- Responsive storefront
- Admin dashboard

## Development roadmap

1. Project foundation
2. Storefront UI
3. Product catalog and search
4. Cart and checkout
5. Authentication
6. Payments
7. Orders and inventory
8. Admin dashboard
9. Security and production deployment
